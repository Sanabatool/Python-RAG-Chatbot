1. 🤖 WHAT IS MACHINE LEARNING?
Machine Learning is teaching a computer to learn patterns from data so that it can make predictions or decisions without being explicitly programmed for every individual case.
ML allows computers to learn from data and past experience and improve performance.

PART 5   POLYNOMIAL REGRESSION
🧒 The problem
Suppose your data looks like this:

A straight line won't fit very well.  So we need a curve.
📈 Polynomial Regression
Polynomial regression is a form of linear regression where the relationship is represented using an nth-degree polynomial. 
Example:
Degree 1 y = θ0 ​+ θ1​x    Straight line.
Degree 2 y = θ0​ + θ1​x + θ2​x2  Quadratic curve.
Degree 3 y = θ0 ​+ θ1​x + θ2​x2 + θ3​x3  Cubic curve.
🧠 MEMORY
Think: 1 = Line      2 = U / ∩       3 = S-like curve
🤯 WHY IS IT CALLED "LINEAR" REGRESSION?
This confuses many students.
Look carefully: y = θ0​ + θ1​x + θ2​x2 
It is nonlinear in x.
But it is still linear in the parameters θ. That's why it can still be treated as a linear model in the coefficients.
